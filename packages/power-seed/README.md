# Power Seed

A powerful database seeding library that works with any relational ORM. Deterministic data support, self-resolving relational dependencies, ultra type-safe.

## Installation

```sh
pnpm install @jack3898/power-seed
```

## Requirements

Any runtime that supports ESM syntax should work, which is most modern JS runtimes.
